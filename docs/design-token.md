# AI Tavern Pro — Design Token

> **版本** `t1.0` · **冻结** 2026-10-12 · **依赖** `docs/stage-0-architecture.md` 附录 B
> **用途**：视觉系统的唯一真源。Stage 1 的 T2 任务据此落地为 `src/styles/tokens.css`，此后**只允许引用 token，不允许在组件里写裸值**。
> **说明**：按 Stage 1-0 约束，本文件不含任何 CSS 代码。对比度数值为冻结时用 WCAG 2.1 相对亮度公式实测得出，非估算。
> **与 Stage-0 的关系**：三个霓虹色与基底色**原样继承 Stage-0 附录 B，未改动**；新增值一律在同色系内推导，已逐条标注「新增」。

---

## 0. 使用规则

1. **三层结构**：`primitive（原始色板）→ semantic（语义角色）→ component（组件级，Stage 1 起追加）`。组件只能引用 semantic，禁止直接引用 primitive。
2. **禁止裸值**：颜色、间距、圆角、时长、缓动一律走 token。唯一例外：`0`、`100%`、`1px` 发丝线、`currentColor`。
3. **命名法**：`--{类别}-{语义}-{变体}`。
4. **对比度先行**：任何新增的前景/背景组合，**必须先用公式实测**，达到 §1.8 的门槛才能加入。低于 3:1 的组合一律禁止使用（无论是否承载信息）。
5. 本文件与 `persona-spec.md` 冲突时：**语义以 persona-spec 为准，色值以本文件为准**。

## 1. Color System

### 1.1 基底与表面（elevation）

| token | 值 | 来源 | 用途 |
| --- | --- | --- | --- |
| `--bg-void` | `#0a0706` | 新增（同色系下探） | 页面最底、遮罩下的世界、强调色上的反色文字 |
| `--bg-tavern` | `#120c0a` | **Stage-0 冻结** | 酒馆主背景 |
| `--bg-surface-1` | `#1d1512` | **Stage-0 冻结** | 面板底 |
| `--bg-surface-2` | `#2a1e18` | 新增 | 面板内嵌块、输入框、列表项 |
| `--bg-surface-3` | `#3a2a20` | **Stage-0 冻结** | 抬起卡片、hover 态 |
| `--bg-scrim` | `rgba(10,7,6,.72)` | 新增 | 遮罩层（**禁止纯黑遮罩**） |

层级语义：surface 序号越大越靠近用户。**不允许跨层跳用**（例如把 surface-3 用作面板底色）。

### 1.2 线条与描边

| token | 值 | 实测（on `--bg-tavern`） | 性质 |
| --- | --- | --- | --- |
| `--line-hair` | `#2e211a` | 1.10 : 1 | 装饰 |
| `--line` | `#4a3527` | 1.69 : 1 | 装饰 |
| `--line-bronze` | `#6b4c33` | 2.50 : 1 | 装饰 |
| `--line-bright` | `#8a6238` | 3.59 : 1 | 可用于 UI 边界（hover/选中描边） |

**规则（重要）**：`line` 系全部是**质感描边，不承载信息**。凡是承载信息的边界 —— focus ring、错误边框、Agent 归属边框、选中态 —— **必须使用状态色或强调色**（实测均 ≥ 5.5:1）。

### 1.3 文本（实测对比度表）

| token | 值 | on `bg-tavern` | on `surface-1` | on `surface-2` | on `surface-3` | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| `--text-1` | `#f4e9dd` | **16.21** | **15.02** | **13.52** | **11.45** | 正文、标题 |
| `--text-2` | `#cbb5a3` | **9.86** | **9.14** | **8.23** | **6.97** | 次级说明、卡片正文 |
| `--text-3` | `#9a8271` | **5.36** | **4.97** | 4.47 ⚠️ | 3.79 ⚠️ | 元信息、时间戳、标签 |
| `--text-disabled` | `#7a6757` | — | 3.34 ⚠️ | — | — | **仅禁用态** |

**约束（冻结）**：
- `--text-3` **只允许用在 `bg-tavern` / `surface-1` / `surface-2` 上**（surface-2 的 4.47 为临界值，使用时必须 ≥ 15px 且不得用于长句）。在 `surface-3` 上（3.79）**禁止**，需要时改用 `--text-2`。
- `--text-disabled`（3.34）**必须同时伴随非色彩线索**（`aria-disabled` + 删除线或图标），不得单独用颜色表达禁用。
- 曾有候选值 `#6b5a4d`（2.73，FAIL）**已从文本token中剔除**，仅作为暗部线条色存在。
- **禁止纯黑文字**（`#000`）与纯白文字（`#fff`）；最深文字用 `--bg-void`，且仅允许出现在强调色底上。

### 1.4 Agent 强调色（G-2 指派）

| Agent | base | soft（浅底/气泡底） | deep（深色/描边） | glow | 实测 on `surface-1` |
| --- | --- | --- | --- | --- | --- |
| **烬 Ember**（bartender） | `#ffb45c` | `#3a2416` | `#c76a1e` | `rgba(255,180,92,.45)` | **10.22** |
| **棱镜 Prism**（oracle） | `#5fe3d4` | `#12302e` | `#1f8f86` | `rgba(95,227,212,.40)` | **11.49** |
| **薇奥拉 Viola**（muse） | `#a482ff` | `#241b3a` | `#6a4fd0` | `rgba(164,130,255,.40)` | **6.18** |

- 三个 base 色**原样来自 Stage-0 附录 B 的霓虹三色**，未做任何色相调整。
- soft 底上的 `--text-1` 实测 11.79 / 12.15 / 13.57，全部安全，可作为气泡与卡片底。
- 反色（强调色底 + `--bg-void` 文字）实测 **11.41 / 12.84 / 6.90**，三者均 ≥ 4.5，**主按钮可用**。
- 同一位置上用 `--text-1` 反而更差：实测 `--text-1` on ember **1.47** / on prism **1.31** / on viola **2.43**，三者全部 FAIL。**结论（冻结）：任何强调色底上一律使用 `--bg-void` 文字，禁止使用 `--text-1`。**
- **每个 Agent 的强调色同时定义其卡片、气泡、Trace 轴与光晕**，是"三个角色"最直接的视觉区分。

### 1.5 状态语义色

| token | 值 | 实测 on `surface-1` | 实测 on `surface-2` | soft 底 | text-1 on soft |
| --- | --- | --- | --- | --- | --- |
| `--state-success` | `#63d69b` | **9.95** | 8.96 | `#17322a` | **11.50** |
| `--state-warn` | `#e8b23c` | **9.30** | 8.37 | `#3a2c14` | **11.32** |
| `--state-danger` | `#ff6b6b` | **6.48** | 5.83 | `#3a1a1c` | **13.05** |
| `--state-info` | `#7aa8ff` | **7.59** | 6.84 | `#1a2438` | **12.96** |

状态色在各自 soft 底上同样达标（5.63 / 7.01 / 7.62 / 6.56），可用于角标与提示条。

### 1.6 Trace 步骤状态映射（**本作品最关键的一组映射**）

| 步骤状态 | 颜色 | 形态（必须，非可选） | 文案 |
| --- | --- | --- | --- |
| `pending` | `--text-3` | 空心圆 + 虚线轴 | 未开始 |
| `active` | 当前 Agent `--accent-base` | 实心圆 + 呼吸脉冲（`--dur-breath`）+ 轴向扫光 | 进行中 |
| `done` | `--state-success` | 实心圆 + 对勾 | + 耗时 `μs/ms` |
| `skipped` | `--state-warn` | 空心圆 + 斜杠 | **必须写原因**："未执行：检索超时" |
| `error` | `--state-danger` | 实心圆 + 感叹 | 失败原因 |

**规则**：颜色**绝不是唯一线索**，每个状态都必须同时具备形态差异 + 文案（色觉障碍可用性）。`skipped` 的文案不是可选项 —— 它是"没有假步骤"红线在 UI 上的落点。

### 1.7 稀有度（卡片边框）

| 等级 | 描边色 | 实测 on surface-1 | 反色文字可用性 |
| --- | --- | --- | --- |
| 铜 | `#8a6238` | 3.59 | ⚠️ `bg-void` on 铜仅 3.71 → **铜级不使用反色文字** |
| 银 | `#b9c2cc` | 9.97 | ✅ 11.14 |
| 金 | `#e0b25a` | 9.15 | ✅ 10.22 |
| 虹彩 | 三强调色线性渐变 | — | 文字一律用 `--text-1` |

避免与 Agent 色相冲突：**稀有度只用金属色 + 边框纹理 + 角标形状**表达，不引入第四种霓虹色。

### 1.8 对比度门槛与禁用组合（冻结）

| 门槛 | 要求 |
| --- | --- |
| 正文（< 18px） | ≥ 4.5:1 |
| 大字（≥ 18px 或 ≥ 14px 粗体）与 UI 边界 | ≥ 3:1 |
| 装饰性描边 | 无门槛，但**不得承载信息** |
| 任何 < 3:1 的组合 | **一律禁止** |

**禁用组合清单**：纯黑 `#000`；紫色底 + 紫色字；琥珀底 + 琥珀字；`--text-3` 于 `surface-3` 上；同时并列 ≥ 3 个强调色（**唯一例外：Trace 面板**，因为多 Agent 并列是功能需要）；彩色阴影滥用（见 §5）。

## 2. Typography

### 2.1 字体栈（Stage-0 冻结：零字体下载）

| token | 值 | 用途 |
| --- | --- | --- |
| `--font-display` | `Georgia, "Times New Roman", "Songti SC", "SimSun", "Noto Serif SC", serif` | 标题、入场标语、卡片标题 |
| `--font-body` | `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 正文、对话 |
| `--font-mono` | `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Cascadia Mono", "Noto Sans Mono CJK SC", monospace` | Trace 面板、耗时、JSON、数值、时间戳 |

**决策理由（冻结）**：Stage-0 允许一个不超过 20KB 的 latin 子集显示字面，但**中文标题无法靠 latin 子集表达**（20KB 仅能覆盖数百汉字，远不足以排标题）。因此本作品**不引入任何外部字体**，标题的"书卷感"由系统衬线（`Georgia` / `Songti`）承担，"技术感"由等宽栈承担。这同时消除了 R1（CDN 不可达）在字体维度的全部风险。Stage 5 若体积富余，可再评估——**不属于冻结项**。

等宽字体是刻意选择：Trace 面板、耗时、坐标、JSON 原文用 mono，是"这不是聊天页"的第二视觉信号。

### 2.2 字号阶梯（流体）

| token | 值 | 用途 | 约束 |
| --- | --- | --- | --- |
| `--fs-display` | `clamp(28px, 4.6vw, 46px)` | 入场标题 | 仅 latin 标题可全大写 |
| `--fs-h1` | `clamp(20px, 2.4vw, 26px)` | 屏标题、Agent 名 | |
| `--fs-h2` | `18px` | 卡片标题、面板标题 | |
| `--fs-body` | `15px` | 中文正文 | **中文正文字号下限** |
| `--fs-body-sm` | `13.5px` | 次级正文、气泡内说明 | |
| `--fs-meta` | `12px` | 元信息、时间戳 | 只能用 `--text-2` 及以上 |
| `--fs-micro` | `11px` | 标签（大写 + 字距） | **禁止承载长句（> 16 字）** |
| `--fs-mono` | `12.5px` | Trace 面板正文 | |
| `--fs-num` | `24px` | 等级/XP 数值跳动 | 配 `--font-mono` |

### 2.3 行高 / 字重 / 字距

| token | 值 | 说明 |
| --- | --- | --- |
| `--lh-body` | `1.75` | CJK 正文，**硬下限 1.7** |
| `--lh-tight` | `1.35` | 卡片标题、面板标题 |
| `--lh-mono` | `1.55` | Trace 面板 |
| `--fw-body` | `400` | |
| `--fw-emph` | `500` | 强调 |
| `--fw-title` | `600` | 标题 |
| `--fw-num` | `700` | 仅数值 |
| `--ls-label` | `0.08em` | 大写英文标签 |
| `--tt-label` | `uppercase` | 仅英文标签（中文禁全大写概念） |

**规则**：
- **CJK 禁止 `font-weight: 300`**（部分系统细体发虚）与**禁止 italic**（合成斜体会歪、笔画断裂）；强调一律用字重 + 颜色。
- 中英文/数字混排必须留视觉间隙。
- 一行正文建议 ≤ 34 个汉字（超出的容器宽度需检查，长文本容器最大宽度约 `66ch`）。

### 2.4 文本效果

| token | 值 | 约束 |
| --- | --- | --- |
| `--glow-text` | `0 0 12px var(--accent-glow)` | **仅标题与数值**；正文禁用发光 |
| `--text-shadow-subtle` | `0 1px 1px rgba(0,0,0,.35)` | 提升暗底可读性 |

禁止：多方向描边式 text-shadow（廉价感）、文字渐变填充（中文小字发糊）、文字逐字随机抖动。

## 4. Radius

| token | 值 | 用途 | 性格 |
| --- | --- | --- | --- |
| `--r-1` | `2px` | 标签、Chip、稀有度角标 | 硬 / 技术 |
| `--r-2` | `6px` | 按钮、输入框、Trace 节点 | 硬 / 技术 |
| `--r-3` | `12px` | 面板、卡片 | 中性 |
| `--r-4` | `20px` | Agent 大卡、肖像框 | 柔 / 叙事 |
| `--r-full` | `999px` | 状态环、头像、心情环 | 柔 |

**美学骨架（冻结）**：小圆角 = 技术/仪表盘（Trace 面板、Dev Drawer 一律 `--r-1`/`--r-2`）；大圆角 = 角色/叙事（Agent 卡、气泡、记忆条目用 `--r-3`/`--r-4`）。**这个对立关系是本作品视觉上的核心张力**，不得随意拉平。

## 6. Motion Rules

### 6.1 时长

| token | 值 | 用途 |
| --- | --- | --- |
| `--dur-instant` | `80ms` | 状态反馈（按下、勾选） |
| `--dur-fast` | `160ms` | hover、图标切换 |
| `--dur-base` | `240ms` | 面板切换、Tab、气泡入场 |
| `--dur-slow` | `420ms` | 卡片入场、记忆脉冲 |
| `--dur-cinematic` | `900ms` | 推门入场、等级提升 |
| `--dur-breath` | `3200ms` | 烛光、状态环呼吸（非匀速循环） |

### 6.2 缓动

| token | 值 | 用途 |
| --- | --- | --- |
| `--ease-panel` | `cubic-bezier(.2,.8,.2,1)` | **Stage-0 附录 B 原值，继承** —— 面板滑动标准 |
| `--ease-standard` | `cubic-bezier(.4,0,.2,1)` | 通用 |
| `--ease-breath` | `cubic-bezier(.37,0,.63,1)` | 呼吸（Stage-0 要求"非匀速"） |
| `--ease-overshoot` | `cubic-bezier(.34,1.56,.64,1)` | 仅卡片入场上浮，每屏 ≤ 1 处 |

### 6.3 编排（stagger）

| 场景 | 规则 |
| --- | --- |
| Trace 步骤点亮 | 首步 180ms 起，后续每步 +60ms；> 6 步压缩为 +30ms（不允许长于 1.2s） |
| 卡片入场 | 整体 420ms，内部元素再 +40ms 递增 |
| 三张 Agent 卡入场 | 起点 120ms，间隔 100ms |
| 记忆脉冲 | 单次 420ms，无并发 |

### 6.4 六条硬规则（冻结）

1. **只有 `transform` 与 `opacity` 参与动画**；`filter` 仅限单元素短时，禁止用于大面板。
2. **可以演进度，不能演状态**：真实结果未到达时，该步骤最多显示 `active`；**绝不允许提前显示 `done`**。真实结果到达后，允许用剩余动画时间把观感补完。这是"没有假步骤"红线的动画版。
3. **流式文本按真实到达节奏渲染，禁止匀速打字机特效**（匀速打字是表演；真实流式有快有慢，那才是"活的"）。
4. 同屏并发动画 ≤ 3 条；粒子 ≤ 300（视口 < 900px 时 ≤ 160）。
5. `prefers-reduced-motion: reduce` → 全部动画降为 opacity 淡入，时长 ≤ 120ms，**粒子层关闭**；`prefers-contrast: more` → `--text-3` 提升为 `--text-2`。
6. 页面进入后台（`visibilitychange`）→ 暂停 rAF 与 CSS 动画（统一挂一个 class 控制）。

### 6.5 记忆脉冲（跨面板唯一的"英雄动画"）

触发条件：**真实 `trace:memory:hit` 事件到达** → 从记忆台对应条目沿最短路径发一条光脉冲到 Trace 面板的记忆节点。规格：420ms、2px 粗、颜色为当前 Agent 的 `--accent-base`、辉光用 `--glow-accent`。
**没有真实命中就不出现 —— 这个动画本身就是"记忆真的被读了"的证据。**

## 8. 材质与背景

| 项 | 规格 | 约束 |
| --- | --- | --- |
| 噪点 | 内联 SVG `feTurbulence`，全屏覆盖，`opacity ≤ .05` | **静态，不参与动画**（动态噪点极耗性能） |
| 暗角 | 径向渐变，中心 60% 起变暗，最暗 `rgba(0,0,0,.55)` | 不遮挡内容 |
| 烛光 | 全屏暖色叠加，`--dur-breath` 呼吸，opacity 在 **.04 ~ .09** 之间 | 幅度小才有质感，幅度大像故障 |
| 粒子 | Canvas 单层，向上飘的余烬；≤ 300 | 分批生成，**禁止逐帧 new 对象** |
| 模糊 | `backdrop-filter` 仅用于弹层，同时 ≤ 2 处 | 必须有 `@supports` 回退为不透明底色 |

## 9. 无障碍与性能红线

1. 正文对比度按 §1.3 的实测值使用；**新增组合必须先实测再加入**（记录在验收清单 A-3）。
2. 状态不得只靠颜色（§1.6）。
3. 键盘：所有可交互元素可达；focus 用 `--ring-focus`；**禁止无条件 `outline: none`**。
4. 移动端点击目标 ≥ 44×44px。
5. 视口高度用 `100dvh`（不用 `100vh`）。
6. 长列表（对话流、记忆台）容器加 `content-visibility: auto`；`will-change` 仅在实际动画期间挂载。
7. 遵守 `prefers-reduced-motion` 与 `prefers-contrast`（§6.4-5）。
