# 3 分钟演示脚本

> 目标：让评审经历「10 秒设计感 → 1 分钟看到思考 → 完整闭环」。
> 离线（Mock）与在线（真实模型）两条链路话术通用，差异点已标注。

## 0:00–0:10 · 第一印象

**操作**：双击 `AI-Tavern.html`（或打开托管链接）。

**解说词**：
- "这是一个单文件作品——零 CDN、零外部资源，断网也能完整运行。"
- "视觉是 Cyber Fantasy Tavern：奇幻酒馆 × AI 未来感 × RPG 界面，刻意不做成聊天框。"

## 0:10–0:40 · 选 Agent，快速轮

**操作**：推门进入 → 选「烬」→ 输入一句带偏好的话（示例："我喜欢雨天的味道"）→ 发送（快速模式）。

**解说词**：
- "三位 Agent 人格与职责不同：烬（规划参谋）、棱镜（知识检索）、薇奥拉（创意生成）。"
- "看右侧 Trace 面板——意图识别、回答策略、记忆检索都是**本地纯计算**，毫秒级真实步骤；顶部徽章标明当前是模拟引擎还是真实模型。"
- "这句'喜欢雨天的味道'在快速轮会生成一条**本地启发式候选**（不调用 LLM，强度 ≤0.35，UI 标注为弱记忆）。"

## 0:40–1:40 · 深潜轮（核心）

**操作**：切「深潜」→ 输入一个值得认真回答的问题（示例："用一句话说明你在做什么"）→ 观察 Trace 逐条亮起。

**解说词（按步骤走）**：
- "深潜 = 三次真实调用：**生成 → 自检 → 记忆抽取**。"
- "推理度量（帧数 / 字节 / 首帧）来自真实模型的思考流——按设计，**原文不展示、不持久化、不进日志**，只留可核对的度量（DR-009）。"
- "回复落地后，自检步骤报告质量检查结果；随后一次**后置调用**从对话里抽取值得长期记住的事实——两次都**不阻塞任何等待**。"
- （在线）"usage 与延迟是真实值；卡片带来源审计——编造的 URL 会被剥掉。"

## 1:40–2:20 · 闭环：记忆台 + 成长档案

**操作**：顶部「记忆台」→ 切换 Agent 标签看配额与记录 → 顶部「成长」。

**解说词**：
- "记忆台显示的是**真实存储**：每条有类型、来源（深潜评估 / 弱记忆 / 对话写入）、命中次数与**按冻结公式实算的有效强度**；没有示例数据——空态就是空的。"
- （可选现场操作）"换个说法再说一句" —— "被想起的事会巩固（命中 +1、强度 +0.03）；改变主意会**冲突合并**——旧记忆强度减半保留，'曾经是'也是信息。"
- "成长档案：等级 / XP / 关系五级 / 信任 / 能量（按真实时间回复）/ 认知档案——由真实记忆本地汇总生成，未实现的解锁如实标注'规划'。"

## 2:20–3:00 · 收尾

**操作**：指一下输入区上方的事件卡（若触发）与关系提示。

**解说词**：
- "关系会随对话演化；事件卡是可选剧情节点——所有数值规则都冻结在规格文档里，可逐条对照。"
- "工程上：单文件双体积门禁、8 个冻结事件契约、19 套测试 300+ 断言。**每个被画出来的步骤，都对应一次真实计算**——这是我们最想展示的东西。"

## 应急话术（网络不可达时）

- "页面探活失败会自动回退**离线模拟引擎**——现在看到的每一步都显式标注为模拟值，功能完整，只是没有真实模型。"（红线：演进度不演状态）

## 可选的深挖点（评审提问时）

| 提问 | 一句话回答 |
| --- | --- |
| 为什么编排在客户端？ | 思考过程要能真可视化——Worker 只做密钥 / 路由 / 限流，不做编排。 |
| 为什么单文件？ | 评审双击本地文件也必须能跑；CDN 在国内会挂。 |
| 预算怎么控制？ | 每次演进都过体积门禁（raw + gzip 双硬上限），超限即停止并报告，历次上调均有授权记录。 |
| 怎么防幻觉？ | 记忆块声明"只允许引用列出的记忆"；卡片来源双向审计；工具结果包 `<untrusted>`；无来源声明降置信度。 |
| 离线模式是假的吗？ | 不——它显式标注每一步为模拟；真实模式下打开同一页面看到的是真实 usage、真实推理度量、真实记忆落库。 |
